# Flashcard Coach

A flashcard app for studying Azure Fundamentals (AZ-900). It uses spaced repetition to help you practice and remember key concepts. Your progress is saved in your browser.

## Features

- Smart review, weak spots, and cram study modes
- Progress tracking by topic
- Flashcards with answer feedback and kitten animations
- Keyboard shortcuts: **Space** to flip a card, **1–4** to grade your answer

## Get started

Install dependencies and start the app:

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Check the app

```bash
npm test
npm run build
```
